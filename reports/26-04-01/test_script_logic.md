# Test Script Logic

## Overview

The test script (`test_gui_params.py`) tests the DDR Timing Table Generator GUI through multiple test suites that verify correctness of parameters, density support, timing fields, and comparison with CLI generation.

## Test Suites

### 1. Parameter Tests (`test_parameters`)
Tests various valid parameter combinations:
- LPDDR4 single/dual channel
- LPDDR5 single/dual channel
- Different densities (4, 8, 16)
- Various orbit config options (byte-mode, mixed, rfm-en, dsm-en, ca-odt)

### 2. Reference Binary Tests (`test_reference_binaries`)
Compares GUI-generated binaries with reference binaries to ensure exact match in timing table section.

### 3. ps/MHz Toggle Tests (`test_ps_mhz_toggle`)
Verifies the conversion formula: `MHz = 1000000 / ps`

### 4. Button Tests
- `test_button_load_binary`: Tests /analyze endpoint
- `test_button_save_json`: Tests JSON structure validity
- `test_button_load_json`: Tests loading params from JSON and generating
- `test_button_generate`: Tests /generate endpoint

### 5. All Densities Tests (`test_all_densities`)
Tests all supported densities:
- LPDDR4: 2, 3, 4, 6, 8, 12, 16
- LPDDR5: 1, 2, 3, 4, 6, 8, 12, 16, 24, 32

### 6. All Timing Fields Tests (`test_all_timing_fields`)
Tests timing fields with random values within valid ranges (10 iterations per field):
- dram-tck
- min-dram-tck
- write-odt-upto
- read-dbi-upto
- write-dbi-upto
- read-lecc-upto
- write-lecc-upto
- wck-1to4-upto
- wck-always-on-upto
- dfs-lvl-t-ck-0/1/2

Valid ranges:
```
TIMING_RANGES = {
    'dram-tck': (300, 5000),
    'min-dram-tck': (200, 3000),
    'write-odt-upto': (1250, 10000),
    'read-dbi-upto': (1000, 10000),
    'write-dbi-upto': (1000, 10000),
    'read-lecc-upto': (500, 2500),
    'write-lecc-upto': (500, 2500),
    'wck-1to4-upto': (625, 2500),
    'wck-always-on-upto': (314, 1256),
    'dfs-lvl-t-ck-0': (500, 3000),
    'dfs-lvl-t-ck-1': (500, 3000),
    'dfs-lvl-t-ck-2': (500, 5000),
}
```

### 7. All Orbit Config Params Tests (`test_all_orbit_params`)
Tests orbit configuration parameters:
- byte-mode (0, 1)
- mixed (0, 1)
- rfm-en
- dsm-en (LPDDR5 only)
- ca-odt
- num-rank (1, 2)
- rank-interleaving
- reboot-with-mrw

### 8. GUI vs CLI Comparison (`test_gui_vs_cli`)
Compares binaries generated by GUI vs CLI to ensure consistency.

### 9. Load-Modify-Generate-Compare (`test_load_modify_generate_compare`)
Tests workflow: load binary → modify params → generate → compare.

## Running Tests

```bash
# Start GUI server first
python3 gui.py &

# Run tests
python3 test_gui_params.py
```

## Expected Results

All tests should pass if:
1. GUI server is running
2. Reference binaries exist (for comparison tests)
3. Input validation is correctly implemented
