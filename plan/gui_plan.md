# DDR Timing Table GUI - Implementation Plan

## Overview
Create a web-based GUI for DDR timing table generation that displays and modifies all CLI parameters, generates `ddr_timing_table.bin`, and creates `ddr_config.h` with modified hardcoded values.

## Goals

1. **Web-based GUI** - runs locally without internet, using Python standard library
2. **All CLI parameters editable** - all parameters from gen_timing_params
3. **Generate ddr_timing_table.bin** - with modified parameters
4. **Generate ddr_config.h** - with all modified and hardcoded values

### Step 4: Generate Functions

**Generate Binary**:
- Call `gen_timing_params` with all GUI parameters via subprocess
- Produces `ddr_timing_table.bin` in current directory

**Generate ddr_config.h**:
- Create new `ddr_config.h` with:
  - User-modified values from GUI (cpipe_depth, dpipe_depth, etc.)
  - All hardcoded values from template
  - ORBIT_DENSITY from orbit_config_density parameter

### Step 5: File Locations

**Generated files in current directory**:
- `ddr_timing_table.bin` - timing table binary
- `ddr_config.h` - generated header with modified values
- `orbit_init_gen.h` - density mapping (generated by gen_timing_params)

**Why current directory**:
- Simpler for users - see files immediately
- Matches CLI behavior
- Easy to find and copy output files

### Step 6: How to Run

```bash
python3 gui.py
# Open browser at http://localhost:5000
```

### Step 7: Package to IDE

- No additional setup needed

## Parameters List

### Basic Parameters
- `--dram-type`: lpddr4 | lpddr5 (required)
- `--densities`: list of densities
- `--phy-name`: PHY name
- `--dq-width`: 4 | 8 | 16 | 32
- `--speed-bin`: speed bin
- `periods`: list of tCK values

### Pipe Parameters
- `--cpipe-depth`: int
- `--dpipe-depth`: int

### Timing Features
- `--write-odt-upto`: int
- `--read-dbi-upto`: int
- `--write-dbi-upto`: int
- `--write-lecc-upto`: int
- `--read-lecc-upto`: int
- `--emulation`: flag

### LPDDR4 Options
- `--wdqs-ctrl-mode`: int
- `--variable-trrd`: flag
- `--txsr-as-1st-ed`: flag
- `--lpddr4-byte-mode`: flag
