# Timing Entry Parsing Validation Test Plan - 2026-04-08

## Purpose

Validate that timing entry parameters parsed from binary (gui.py parse_timing_entries) match the values generated by gen_timing_params.

## Critical: Different Periods → Different Timing Values

When periods change, timing entry params also change:

| Period (t_ck) | freq (MHz) | RL | WL | timing_param values |
|---------------|------------|----|----|---------------------|
| 471 | 2123 | 14 | 10 | Larger (faster timing) |
| 938 | 1066 | 10 | 8 | Medium |
| 1631 | 613 | 8 | 6 | Smaller |
| 2500 | 400 | 6 | 4 | Smallest (slower timing) |

**Key validation**: For each period input, the parsed timing_param values must match what gen_timing_params generates.

---

## Test Strategy

1. Generate binary for each test configuration using gen_timing_params
2. Parse binary using gui.py analyze_binary_file()
3. Compare parsed values against expected values from generation
4. Validate field constraints and edge cases

#### Step 1: Setup

- Create temp directory for test outputs

```

TC3: gen_timing_params -d lpddr5 --densities 16 --periods "1256 796 556 2500"
TC4: gen_timing_params -d lpddr5 --densities 16 32 --periods "1256 796 556 2500" --two-channel

Outputs: ddr_timing_table.bin, timing_params.c, orbit_init_gen.h, mr_config_gen.h
```

#### Step 3: Parse Binary
```
result = analyze_binary_file(bin_path)
parsed = result['data']['timing_entries']
  - entries[] (4 entries)
  - common{}
  - density_dependent{}
  - selected_density
```

#### Step 4: Extract Expected from C Header
```
Open timing_params.c
Parse each struct timing_param entry
Extract: t_ck, rl, wl, timing_param[0-20], timing_derate[0-1], dfi_timing_param[0-7]
Store as expected_entries[]
```

#### Step 5: Compare Entry-by-Entry
```
For i in 0..3:
  - Compare t_ck: parsed[i].t_ck == expected[i].t_ck
  - Compare freq: parsed[i].freq == expected[i].freq
  - Compare rl: parsed[i].rl == expected[i].rl
  - Compare wl: parsed[i].wl == expected[i].wl
  - Compare timing_param[0-20]: all 21 values match
  - Compare timing_derate[0-1]: both values match
  - Compare dfi_timing_param[0-7]: all 8 values match
```

#### Step 6: Validate Constraints
```
- RL decreases: entries[0].rl > entries[1].rl > entries[2].rl > entries[3].rl
- WL decreases: entries[0].wl > entries[1].wl > entries[2].wl > entries[3].wl
- All timing_param > 0
- Density arrays: len == 7 (LP4) or 10 (LP5)
- LP5: read_link_parity > 0, write_link_parity > 0
```

#### Step 7: Report Results
```
For each TC:
  Print: "TCX: [PASSED/FAILED]"
  If failed: print mismatch details
Print: "Summary: X passed, Y failed"
```

#### Step 8: Cleanup
```
Remove temp directory
Exit(0) if all passed, Exit(1) if any failed
```

        """Generate test binary using gen_timing_params."""
        # Create temp dir

        cmd = [
            sys.executable, 'gen_timing_params',
            '-d', dram_type,

def compare_with_expected(parsed_entries, expected_entries):
    """Compare parsed values with expected from C header."""
    errors = []
    
    for i, (parsed, expected) in enumerate(zip(parsed_entries, expected_entries)):
        # Check t_ck
        if parsed['t_ck'] != expected['t_ck']:
            errors.append(f"Entry {i} t_ck: expected {expected['t_ck']}, got {parsed['t_ck']}")
        
        # Check rl, wl
        if parsed['rl'] != expected['rl']:
            errors.append(f"Entry {i} rl: expected {expected['rl']}, got {parsed['rl']}")
        if parsed['wl'] != expected['wl']:
            errors.append(f"Entry {i} wl: expected {expected['wl']}, got {parsed['wl']}")
        
        # Check timing_param[0-20]
        for j in range(21):
            if parsed['timing_param'][j] != expected['timing_param'][j]:
                errors.append(f"Entry {i} tp[{j}]: expected 0x{expected['timing_param'][j]:08x}, got 0x{parsed['timing_param'][j]:08x}")
        
        # Check timing_derate[0-1]
        for j in range(2):
            if parsed['timing_derate'][j] != expected['timing_derate'][j]:
                errors.append(f"Entry {i} derate[{j}]: expected 0x{expected['timing_derate'][j]:08x}, got 0x{parsed['timing_derate'][j]:08x}")
        
        # Check dfi_timing_param[0-7]
        for j in range(8):
            if parsed['dfi_timing_param'][j] != expected['dfi_timing_param'][j]:
                errors.append(f"Entry {i} dfi[{j}]: expected 0x{expected['dfi_timing_param'][j]:08x}, got 0x{parsed['dfi_timing_param'][j]:08x}")
    
    return errors

## Debugging Tips

If parsing fails:

1. **Check entry detection**: Verify enable flag offsets
   - write_odt: +0x10A
   - write_dbi: +0x10C
   - read_dbi: +0x10D

2. **Check timing_param offsets**: Should be +0x0C to +0x5C

3. **Check common params offsets**: Should be +0x106 to +0x10F

4. **Check density arrays**: Should be 0x80-0xFE

5. **Dump binary**: Use hexdump to verify raw values
   ```bash
   xxd -s 0x000 -l 0x130 ddr_timing_table.bin  # First entry
   xxd -s 0x80 -l 0x80 ddr_timing_table.bin    # Density arrays
   ```
